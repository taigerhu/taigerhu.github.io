ThinkPad X230 升级 AX200 全纪录

2026-03-11

我的 X230 原网卡是 Intel Centrino Wireless-N 2200。平时 SSH 连家里的服务器，虽然能用，但有时会卡，从服务器复制文件速度也只有 3~4MB/s。看了一圈，可以上 Wi-Fi 6 网卡。

不过，X230 有 BIOS 白名单机制，只允许使用它认证过的无线网卡。想用新网卡（如 Intel AX200/AX210），必须解除白名单, 需要用到工具1vyrain。

第一步：解除白名单

我的 X230 原 BIOS 版本高于 2.60，不能直接破解，必须先降级。这一步需要两个工具：

  • IVprep：用于将 BIOS 降级到 2.60
  • 1vyrain：用于刷入修改版 BIOS（解除白名单）

1.1 降级 BIOS（用 IVprep）

  1. 下载 IVprep 工具（可从 GitHub 的 n4ru/IVprep 获取）
  2. 在 Windows 下直接运行 downgrade.bat
  3. 电脑会自动重启，开始降级刷写。过程中绝对不能断电或关机！
  4. 降级完成后再次重启，进入 BIOS 确认版本已变为 2.60

1.2 准备 1vyrain 启动盘

  1. 下载 1vyrain_20200620.iso 镜像（官网无法访问，我用的是参考资料提供的版本）
  2. 用 Rufus 将镜像写入 U 盘，写入模式选“DD 模式”

1.3 进入 BIOS 设置

开机按 F1 进 BIOS，确保以下设置：

  • Security → UEFI BIOS Update Option → Flash BIOS Updating by End-User 设为 Enable
  • Secure RollBack Prevention 设为 Disabled
  • Security → Secure Boot 设为 Disable
  • Startup → UEFI/Legacy Boot 我这里是 UEFI Only

保存退出。

1.4 启动到 1vyrain 并刷机

  1. 插上制作好的 U 盘，开机按 F12 选择从 U 盘启动
  2. 进入 1vyrain 主菜单选择1 (Flash Modified Lenovo BIOS)等待刷写完成。

1.5 验证刷机成功

重启后按 F1 进 BIOS，如果看到多了一个 “Advanced”（高级）菜单，就说明刷机成功了，白名单已解除。

第二步：购买网卡

我买的是 fenvi 的 MPE-AX3000H，62 元。这块卡是 Mini-PCIe 接口，自带 IPEX 1 天线座，X230 原装天线可以直接插，不需要转接板和转接线。

下载fenvi提供的驱动包，最新的就是 BT&WIFI-23.40.0, 省得去 Intel 官网找了。

第三步：拆机更换网卡

3.1 拆机准备

关机，拔电源，拆下电池，卸下螺丝，取下键盘和掌托，注意排线，看到无线网卡。

3.2 拆卸原网卡

小心拔下两根天线，卸下固定螺丝，网卡会自动翘起，取出即可。

3.3 安装新网卡（MPE-AX3000H）

对准卡槽插入新卡，拧上螺丝，对准座子小心插入天线，确保扣紧。

第四步：安装驱动（Win10 + Ubuntu 20）

4.1 Windows 10 下的情况

装好网卡后开机，安装之前下载的驱动包。

Wi-Fi：一次成功

网络适配器中直接识别出 Intel(R) Wi-Fi 6 AX200 160MHz，连接 5G Wi-Fi 正常。

蓝牙：一波三折

设备管理器里出现了 英特尔(R) 无线 Bluetooth，但带黄色感叹号。蓝牙工作不正常，进控制面板看到驱动列表里有个 “Broadcom Corporation (bctbums) Bluetooth” 驱动，不太对，卸载后再装。

黄色感叹号还在（Windows 没认出设备名称），但试了下我的漫步者蓝牙耳机可以配对、听歌。

4.2 Ubuntu 下的情况（意外省心）

换完网卡第一次开机直接进了 Windows，看不到 GRUB 菜单, 改下启动顺序就可以。

进入 Ubuntu 后，Wi-Fi 和蓝牙直接工作。

📊 性能对比：

场景 原装 N2200 MPE-AX3000H 提升
远程复制文件 3~4 MB/s 17~23 MB/s 5~6 倍

🏁 写在最后

至此，我的 ThinkPad X230 无线网卡升级之旅圆满完成：

  • ✅ BIOS 破解：1vyrain 降级 + 刷修改版 BIOS，解除白名单
  • ✅ 硬件更换：MPE-AX3000H（fenvi 版）完美匹配 X230，原装天线直插
  • ✅ Wi-Fi 6：速度飞起
  • ✅ 蓝牙：虽然有个“看着不舒服”的感叹号，但耳机正常用
  • ✅ 双系统：Win10 + Ubuntu 均正常工作
  • ✅ 真实速度：远程复制文件从 3~4MB/s 提升到 17~23MB/s

美！
